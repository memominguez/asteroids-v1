# Gazing asteroids
- This React application links to a NASA API for getting information about our neighbor asteroids.  
- When a particular asteroid is considered as hazardous, the displayed asteroid's name is highlighted with a reddish color.   
- The displayed information is automatically updated every day, so the data is always taken from "yesterday".  
- The titles and comments are in Spanish language.    
- The application was created by "vite@latest" in November 2026. So React version shown as 19.3.1. No external libraries were installed.
